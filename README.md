# PhysMath Telegram Bot

## Как пользоваться

1. Скопируй `.env.example` и переименуй в `.env`, заполни свои данные:
   - `TOKEN` — токен от @BotFather
   - `OWNER_ID` — твой Telegram ID

2. Запускай через Railway (или локально):

```bash
python main.py
```

## Команды

- `/start` — приветствие с кнопками
- Сообщение типа `@username 17:00` — добавляет ученика
- Автонапоминания за 10 минут до занятия
